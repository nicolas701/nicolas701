### 🟥 Red Hat OpenShift

- Day-2 operations of **OpenShift 4.x** clusters across dev, QA and production (multi-site active/contingency).
- Lifecycle of **Operators with OLM**: subscriptions, InstallPlan approval automation and upgrades driven by GitOps.
- Networking on **OVN-Kubernetes**: Routes, Ingress Controllers (HAProxy), **Gateway API**, NetworkPolicies and egress through corporate proxies.
- **OpenShift Service Mesh 3 (Istio/Envoy)**, **cert-manager** and **Red Hat Connectivity Link (Kuadrant)**.
- Observability with **cluster and user workload monitoring** (Prometheus, Alertmanager, ServiceMonitors), Grafana and Loki.
- Running **Red Hat 3scale API Management** (API Manager and APIcast) and **Developer Hub (Backstage)** on top of OpenShift.
- OpenShift on **AWS** and on **Azure (ARO)**, besides on-prem clusters.

### ☸️ Kubernetes

- **GitOps** for everything with **Argo CD**: ApplicationSets (list, git and matrix generators), RollingSync and app-of-apps.
- Packaging with **Helm** charts and **Kustomize** overlays for multiple clusters and environments.
- Workload design: Deployments, Jobs and hooks, PDBs, anti-affinity, HPA, probes (readiness, liveness and startup) and resource tuning (CPU throttling, cgroup v2).
- High availability for stateful dependencies: **Redis Sentinel** and **Valkey** as shared storage for rate limiting.
- Security: RBAC, NetworkPolicies, secrets with **HashiCorp Vault** and External Secrets.
- Load testing with **k6** and root cause analysis for production incidents.

### ☁️ AWS

- **OpenShift on AWS** labs and PoCs: Gateway API, Kuadrant and Developer Hub.
- **Amazon EKS**: Kuadrant and Argo CD deployments for public cloud workloads.
- **Route 53** DNS automation with Kuadrant `DNSPolicy`, and **ElastiCache** as an external counter store for Limitador.
- Core building blocks: **EC2**, **VPC**, **ELB/NLB**, **EBS**, **S3** and **IAM** (least-privilege roles and credentials for in-cluster controllers).
